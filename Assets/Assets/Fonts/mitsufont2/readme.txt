mitsufont2（みつフォント2）

2012年9月初版作成

#############################################################################


■概要

TrueTypeフォントです。シフトJIS範囲の7450文字をカバーしています。

前バージョンのMitsuFontでの反省を踏まえ、紙で書きスキャンするのではなく、直接ペンタブレットで文字を書いて作成したデータからフォントを作成しました。武蔵システムさんの「手書きでフォント」（http://opentype.jp/tegakidefont.htm）を使用しています。

■作者連絡先
内藤光春
Email : mit@dokasen.com
URL   : http://dokasen.com/

■取扱種別
フリーソフトです。フォントそのものの単純な再配布は不可ですが、プログラム等の動作の為に補助的に同梱するのは可です。

■動作環境
Windows
MacOSX
Linux
その他、TrueTypeフォントが使用可能なシステムなら動作可能です。

■インストール・アンインストール方法
オペレーティングシステムのフォントディレクトリに本.ttfファイルを配置して下さい。
不要になった場合は、当該ディレクトリから本.ttfファイルを削除して下さい。
その他、スクリプト言語では妥当なディレクトリに配置して本.ttfファイルを読み込んでください。
